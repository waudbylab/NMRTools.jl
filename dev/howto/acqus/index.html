Find acquisition parameters

When a spectrum or FID is loaded, the Bruker acquisition files (acqus, acqu2s, …), the pulse programme and any lists in the experiment folder are read. acqus looks up their values.

using NMRTools
spec = exampledata("2D_HN")

Parameters

Give a parameter name, as a string in any case ("TE", "te") or a lowercase symbol (:te):

acqus(spec, :te), acqus(spec, "PULPROG"), acqus(spec, :ns)
(276.9988, "sfhmqcf3gpph.cw", 2)

Times are converted to seconds and frequencies to Hz (see Time and frequency units).

Arrayed parameters

Pulse lengths, delays, powers and other arrayed parameters take an index, as numbered in TopSpin:

acqus(spec, :p, 1), acqus(spec, :d, 1)
(9.199999999999998e-6, 0.1)

Without an index the whole array is returned, as a dictionary keyed by the TopSpin index, so d[0] is D0:

d = acqus(spec, :d)
d[0], d[1]
(0.0003291353, 0.1)

Arrays are dictionaries rather than vectors to avoid confusion between Bruker arrays, which count from zero, and Julia arrays, which count from one.

Indirect dimensions

Parameters from acqu2s, acqu3s, … are under the keys :acqu2s, :acqu3s of the spectrum metadata:

spec[:acqu2s][:td]
128

Most dimension-specific values are also in each dimension's metadata, for example spec[F2Dim, :td] or spec[F2Dim, :swhz].

Power levels

Power levels are returned as Power objects, which convert between dB and W:

p = acqus(spec, :plw, 1)
watts(p), db(p)
(6.999999999999998, -8.450980400142567)

See Power levels, including conversion to RF field strength.

Spectrometer channels

Frequency dimensions carry their own :bf, :sf and :nucleus metadata, but only for detected nuclei. To reach a nucleus that was pulsed but never detected, such as the carbon channel of a ¹³C-edited experiment read out on ¹H, use the channel model. channels(spec) returns all the RF channels (:f1…:f8), and channels(spec, ...) one channel, by label, by Nucleus or by a string:

channels(spec, :f1)
Dict{Symbol, Any} with 6 entries:
  :offsethz  => 2819.0
  :nucleus   => H1
  :offsetppm => 4.69677
  :label     => :f1
  :sfo       => 6.00203e8
  :bf        => 6.002e8
channels(spec, "13C")[:bf]     # carbon base frequency, with no carbon axis
1.5092041e8

Each channel dictionary has keys :label, :nucleus, :bf (base frequency, Hz), :sfo (carrier frequency, Hz), :offsethz and :offsetppm.

Lists

vclist, vdlist, valist, vplist and frequency lists (fq1list…) in the experiment folder are read too:

relax = exampledata("pseudo2D_T2")
acqus(relax, :vclist)
16-element Vector{Int64}:
   1
   2
   4
   8
  12
  16
  24

Values are converted to NMRTools units: delays and pulse lengths in seconds, amplitudes in dB, and frequency lists as FQList objects (see Frequency lists). acqus returns nothing for a list that is not present.

Pulse programme annotations

Pulse programmes annotated with NMRTools' annotation format describe their own parameters; see Pulse programme annotations.

Without loading the data

loadmetadata reads the acquisition metadata of an experiment folder without loading any spectrum, and scanexperiments does this for every experiment in a folder (see Find sample information).
