NMRTools.NMRBase.Peak — Type
Peak{N}

A peak in an N-dimensional frequency-domain spectrum: where it is, how big it is, how broad it is, and what it is called.

A peak records what was picked, not what a fit produced. Positions are in ppm and linewidths are full widths at half maximum in Hz, both ordered like the dimensions of the spectrum the peak came from, so for a 2D spectrum the first coordinate is the direct dimension (x) and the second the indirect dimension (y). Linewidths are kept in Hz because, unlike ppm, they mean the same thing on every nucleus and at every field; the corresponding relaxation rate is R2 = π * linewidth.

Unknown quantities are NaN: a peak read from a Sparky list has a position and label but no intensity or linewidth.

A peak list is simply a Vector{Peak{N}}, so sort, filter, push!, deleteat! and indexing all work as usual. Peak lists are also Tables.jl tables, so DataFrame(pks) works directly.

Examples

p = Peak(8.21, 120.4; label="G10")      # a 2D peak with only a position and label
ppm(p)                                    # (8.21, 120.4)
p = Peak(p; label="G10N")                 # a copy with a new label

pks = detectpeaks(spec)                   # Vector{Peak{2}}
sort(pks; by=intensity, rev=true)

See also detectpeaks, findpeak, findnearest, ppm, intensity, linewidth, loadpeaks and savepeaks.

NMRTools.NMRBase.Power — Type
Power{T}

A type to represent NMR pulse powers that can be described either in Watts (W) or as dB attenuation (dB). Internally stores the dB value as type T.

Constructors

  • Power(value, :dB) - Create from dB attenuation value
  • Power(value, :W) - Create from Watts value

Getters

  • db(p::Power) - Get dB attenuation value
  • watts(p::Power) - Get Watts value

Examples

# Create power from dB attenuation
p1 = Power(30.0, :dB)
db(p1)    # 30.0
watts(p1) # 0.001

# Create power from Watts
p2 = Power(0.5, :W)
watts(p2) # 0.5
db(p2)    # ≈ 3.01

# Works with integers and other numeric types
p3 = Power(10, :W)
db(p3)    # -10.0

# Zero watts is represented as 120 dB attenuation
p4 = Power(0.0, :W)
db(p4)    # 120.0

Conversion

Converting W to dB: -10 * log10(plW) Converting dB to W: 10^(-dB/10)

NMRTools.NMRBase._referencetrace — Method
_referencetrace(spec, di) -> Vector{ComplexF64}

Complex trace along array dimension di of spec, in the imaginary unit given by that dimension's :mcindex. Other imaginary units take their real component. Other dimensions are reduced so that every signal contributes: a time dimension contributes its first point, a frequency dimension is summed over the points that carry signal (see _signalindices), and any other dimension is summed.

A frequency dimension is not summed over all its points: that sum is its first time point, which is dominated by the solvent and baseline rather than the cross peaks, and it adds the noise of every point while signal comes from only a few.

_removegroupdelay!(A, unit, di, g)

Remove a digital-filter group delay of g points from the spectrum A (immediately after the FFT along array dimension di, before fftshift) by multiplying by the linear phase ramp exp(2πi·g·k/N), with k the signed frequency index.   1. With rebuild=true, rebuild points missing at the start of a FID that begins after t = 0 (as loadfid reports for data modified by TopSpin's cryoproc1d), by backward linearpredict.
  2. Suppress the water signal in the direct dimension with solventfilter.

NMRTools.NMRBase.estimatenoise — Method
estimatenoise(nmrdata) -> NMRData

Estimate the rms noise level in the data and update :noise metadata. Returns the NMRData object with noise estimate stored in metadata.

If called on an Array of data, each item will be updated.

Algorithm

Data are sorted into numerical order, and the highest and lowest 12.5% of data are discarded (so that 75% of the data remain). These values are then fitted to a truncated gaussian distribution via maximum likelihood analysis.

The log-likelihood function is:

\[\log L(\mu, \sigma) = \sum_i{\log P(y_i, \mu, \sigma)}\]

where the likelihood of an individual data point is:

\[\log P(y,\mu,\sigma) = \log\frac{ \phi\left(\frac{x-\mu}{\sigma}\right) }{ \sigma \cdot \left[\Phi\left(\frac{b-\mu}{\sigma}\right) - \Phi\left(\frac{a-\mu}{\sigma}\right)\right]}\]

and $\phi(x)$ and $\Phi(x)$ are the standard normal pdf and cdf functions.

Examples

spec = loadnmr("experiment/1/pdata/1")
spec = estimatenoise(spec)  # Estimate and store noise level
spec[:noise]  # Access the noise estimate

NMRTools.NMRBase.estimatephase — Function
estimatephase(spec, [dim]; order=1, p1=0, maxdelay=20e-6, pivot=nothing, snr=10,
              coupling=20, maxwidthratio=3, maxresidual=30, λ=20, edges=0.01, kw...)
    -> NamedTuple
estimatephase([dim]; kwargs...)

Estimate the zero- and first-order phase correction (degrees) for dimension dim (default: the direct dimension) of a frequency-domain spectrum. Returns (p0, p1, pivot, residual, nlines, rejected, edges), where phase(spec, dim, p0, p1; pivot) applies the correction, residual is the weighted rms phase error (degrees) of the observations used, nlines the number of line groups used, rejected lists the line groups left out of the fit as (shift, residual, relsnr), strongest first, where relsnr is the signal-to-noise ratio relative to the strongest group used, and edges lists the edge observations as (edge, snr, residual, used). A large residual, a small number of groups, or a strong rejected group means the estimate should not be trusted. autophase warns when strong groups are rejected.

The forms without the data argument return a function for use with |>.

Lines are found with estimatepoles. Poles within a coupling constant of each other are grouped, because the lines of a multiplet can carry antiphase dispersive components that cancel only in the sum. Each group's phase is the argument of the integral of the spectrum over a window around the group (up to four linewidths beyond its outer lines, and no more than halfway to the next group), less a linear baseline through the ends of the window. Poles much broader than the typical linewidth are ignored when they overlap a narrower line, since they then model its tails or the baseline. The correction is the weighted circular regression of group phase against position, taken modulo 180° so that negative peaks are not treated as phase errors. Groups with a residual above maxresidual degrees are discarded and the fit repeated. The 180° ambiguity is resolved by a majority vote of the groups, so that most lines are positive.

The edges of the spectrum add two observations. With the correct phase the real part is flat far from the lines, while the imaginary part carries the dispersion tails of the strong lines; the phase at which the real part of each edge region vanishes is used as a further observation, weighted by its signal-to-noise ratio. These are most informative for spectra with strong or broad signals, such as protein spectra with residual water. They are skipped when their signal-to-noise ratio is below snr, and used only if they agree with the fit to the line groups within three times the combined uncertainty of the groups' scatter and the edge's own 2° (and maxresidual), so that they refine the line-based estimate rather than override it. Observations are weighted by inverse variance, combining their signal-to-noise ratio with a systematic uncertainty: the scatter of the line groups about the fit (a scaled median absolute residual, so that a few noise groups do not inflate it), or 2° for an edge.

Keywords

  • order: 1 fits p0 and p1; 0 fits p0 only, with the first-order phase fixed at p1.
  • p1: expected first-order phase (degrees). Close to zero once the digital-filter group delay has been removed.
  • maxdelay: largest timing error (seconds) to allow for. A first-order phase is a shift of the time origin: an error of τ gives a first-order phase of 360°·SW·τ across the spectral width SW, so the search covers p1 ± 360·SW·maxdelay degrees. The default of 20 µs covers the residual dead-time and receiver delays of most experiments; it gives ±100° for a 14 kHz ¹H spectrum and ±950° for a 130 kHz ¹⁹F spectrum.
  • pivot: chemical shift (ppm) at which p0 is reported. Defaults to the first point, as for TopSpin's PHC0/PHC1.
  • snr: minimum signal-to-noise ratio of lines used.
  • coupling: poles closer than this (Hz, plus their mean linewidth) are grouped as one multiplet.
  • maxwidthratio: poles broader than this multiple of the median linewidth are ignored when a narrower line lies within their linewidth.
  • maxresidual: groups further than this (degrees) from the fitted phase are discarded.
  • λ: strength of the prior pulling the first-order phase towards p1. It is scaled by the variance of the phase residuals and divided by the effective number of observations, so it matters when few observations determine the fit or their phases scatter, and not when many agree closely. Increase it when the lines cover only a small part of the spectrum, so p1 is poorly determined.
  • edges: fraction of the spectrum at each end used as an edge observation; 0 disables them. Points within four linewidths of a line are excluded.
  • Other keywords (exclude, bandwidth, …) are passed to estimatepoles. Use exclude to drop solvent or buffer lines.

See also autophase, phase.

NMRTools.NMRBase.estimatepoles — Function
estimatepoles(spec, [dim]; bandwidth=:auto, ncoef=16, snr=5, maxlinewidth=nothing, exclude=())
    -> Vector{Pole}
estimatepoles([dim]; kwargs...)

Model a frequency-domain spectrum along dim (default: the direct dimension) as a sum of Lorentzian lines, by band-wise harmonic inversion (HSVD), and return one Pole per line, sorted by decreasing chemical shift. The spectrum may be unphased: the phase of each line is part of the result.

The forms without the data argument return a function for use with |>.

The spectrum is split into overlapping bands of bandwidth points. Each band is inverse Fourier transformed to a short time signal (using only the part covering acquired, not zero-filled, points) and fitted with ncoef damped exponentials. Poles are kept from the central half of each band only, to avoid edge artefacts; bands wrap around the ends of the spectrum, which is periodic. Bands with no signal above the threshold are skipped.

For multidimensional data, the trace along dim takes the first point of every other time dimension, sums every other frequency dimension over the points that carry signal, and sums any remaining dimensions.

Keywords

  • bandwidth: band size in points. :auto uses n ÷ 32 (a power of two between 256 and 4096) for an n-point spectrum.
  • ncoef: number of exponentials fitted per band.
  • snr: minimum signal-to-noise ratio (peak height / noise) for a pole to be kept.
  • maxlinewidth: largest linewidth (Hz) kept; broader poles model baseline rather than lines. Defaults to an eighth of the band width in Hz.
  • exclude: chemical-shift intervals (ppm) to ignore, for example [4.6 .. 4.9] to drop water.

See also estimatephase, autophase.

NMRTools.NMRBase.linearpredict — Method
linearpredict(spec, [dim]; npoints=nothing, factor=2, order=:auto, direction=:forward,
              replace=0, rootfix=true, pool=true)

Extend a time dimension by linear prediction, or rebuild its first points.

Linear prediction models each FID as a sum of decaying oscillations, using the autoregressive coefficient method of nmrPipe and nmrglue, and extrapolates it by recurrence. Forward extension uses the Zhu–Bax scheme: it fits backward coefficients, reflects the roots of the prediction polynomial inside the unit circle, and builds forward coefficients from them, which keeps the extrapolation stable.

With no dimension argument, every indirect Fourier dimension is extended. Prediction uses the FID from t = 0; digital-filter build-up points before t = 0 are left unchanged.

Keywords

  • npoints: length after prediction. Defaults to factor times the current length.
  • factor: length multiplier used when npoints is not given.
  • order: number of prediction coefficients. :auto uses clamp(td ÷ 2, 8, 32).
  • direction: :forward appends points; :backward prepends them and moves the start of the time axis back. Backward extension rebuilds points missing at the start of a FID that begins after t = 0 (see loadfid).
  • replace: if greater than 0, replace that many points from t = 0 by backward prediction, keeping the length unchanged. Overrides npoints and direction.
  • rootfix: reflect unstable roots so that the extrapolation cannot grow.
  • pool: estimate one set of coefficients from the strongest vectors and apply it to all of them. Vectors along one dimension share the same frequencies, so this is valid and much faster than fitting each vector separately (pool=false, as nmrglue does).

Use on time-domain data, before apodize. The :td metadata is updated.

Examples

fid |> linearpredict(T2Dim) |> apodize |> zerofill |> ft     # double the indirect dimension
linearpredict(fid, T1Dim; replace=2)                          # rebuild the first two points

peaklist(shifts, atoms...) -> Vector{Peak{N}}

The peaks expected in an N-dimensional experiment, assembled from a list of assigned chemical shifts (see loadbmrb). Dimensions are given in the order of the spectrum, direct dimension first.

By atom name. Each argument names an atom, optionally with a residue offset relative to the residue that the peak belongs to: "CA-1" is the Cα of the preceding residue. By nucleus. Passing H1 and another nucleus gives one peak for every directly bonded pair of atoms with assigned shifts: every N–H for an ¹⁵N HSQC, including side-chain NH and NH₂ groups, or every C–H for a ¹³C HSQC. Methyl and methylene protons with identical shifts give a single peak.

NMRTools.NMRBase.register! — Method
register!(peaks, spec; maxshift=nothing) -> peaks
register(peaks, spec; maxshift=nothing) -> Vector{Peak{N}}
register!(spec; maxshift=nothing)
register(spec; maxshift=nothing)

Translate a peak list onto a spectrum: find the single offset, applied to every peak, that best matches the list to the signals observed in spec, and move the peaks by it. register returns a moved copy and leaves peaks unchanged. The offset found is reported with @info.

The forms without the data argument return a function for use with |>.

This corrects for referencing differences, e.g. between a list predicted from BMRB shifts (see loadbmrb) and a spectrum recorded under different conditions. It does not move peaks individually.

The match is scored as $\sum_i \log(1 + |S(\delta_i + \Delta)| / \sigma)$: the absolute intensity of the spectrum $S$ at each shifted peak position, so that negative peaks count as much as positive ones, in units of the noise $\sigma$. The logarithm gives diminishing returns for very intense signals, so that many peaks landing on signal outweigh one peak landing on a huge one. To tolerate small disagreements between individual peaks, each point of the spectrum takes the largest absolute intensity among its immediate neighbours.

Every whole-point offset within maxshift is tried, so the match is global rather than the nearest local optimum, and the best is then refined to a fraction of a point. maxshift is the largest offset considered in each dimension in ppm, as a tuple or a single number, and defaults to 10% of the spectral width. Set it to 0 in a dimension to hold that dimension fixed.

Examples

pks = loadbmrb(15000, H1, N15)
register!(pks, spec)                        # shift the BMRB list onto the HSQC
register!(pks, spec; maxshift=(0.3, 2.0))   # search at most ±0.3 ppm ¹H, ±2 ppm ¹⁵N
register!(pks, spec; maxshift=(0.3, 0))     # shift ¹H only

Which value applies is set by the acquisition parameters:

  • DIGMOD = 0 (analogue filtering): no group delay.
  • DSPFVS 20–23: GRPDLY. For baseopt acquisitions (DIGMOD = 3) it is an integer and the spectrometer has already corrected the initial points of the FID.
  • DSPFVS 10–19 (older data): the delay should be looked up from DECIM and DSPFVS. This is not implemented; GRPDLY is used if valid, otherwise no delay is applied, with a warning.
  • DSPFVS outside 10–23: not a firmware version Bruker defines. TopSpin's cryoproc1d, for example, sets DSPFVS = 0 after rewriting the FID with its start removed: the filter build-up and some points after time zero. The number of points removed is found by comparing TD in acqu (the original) and acqus; the points beyond GRPDLY were after time zero, so the stored FID starts that many dwells after t = 0. This is returned as a negative delay, so that ft restores the time origin. A warning reports the missing points. If acqu does not show how many were removed, no delay is applied.

NMRTools.NMRIO.loadfid — Method
loadfid(filename; removefilter=true, firstpoint=nothing) -> NMRData

Load raw Bruker time-domain data (fid for 1D, ser for nD) as an NMRData with Multicomplex elements and TimeDimension axes, ready for processing. filename is the fid or ser file or the experiment folder.

Phase-sensitive indirect dimensions (States, States-TPPI, echo/anti-echo) are combined into extra imaginary units, so a 2D experiment has Multicomplex{Float64,2,4} elements and even 1D data use Multicomplex{Float64,1,2}. Each time dimension records its imaginary unit in :mcindex (T1Dim → 1, T2Dim → 2, …). Non-Fourier dimensions such as a relaxation series become X2Dim/X3Dim with :mcindex == nothing. Intensities match TopSpin's: the raw data are scaled by 2^NC as TopSpin scales them, and ft applies no normalisation.

Keywords

  • removefilter: account for the digital filter's group delay. The filter's build-up points stay in the FID, on a time axis that starts GRPDLY dwell times before zero, and the delay is recorded in the direct dimension's :grpdly metadata. ft removes it with a linear phase ramp, as TopSpin and NMRPipe do. With false, the time axis starts at zero and no delay is recorded.
  • firstpoint: scaling factor for the t = 0 point of each time dimension, as a number for all dimensions or a dictionary keyed by dimension type, for example Dict(T2Dim => 1.0). The default is 0.5, except in the direct dimension of baseopt data (DIGMOD = 3), where the spectrometer already gives the t = 0 point its half weight, and 1.0 is used.

FIDs modified by TopSpin's cryoproc1d (DSPFVS outside 10–23) have had their first points removed. loadfid compares TD in acqu and acqus to find how many points after t = 0 are missing, starts the time axis there, and warns. The missing points leave a ripple around strong lines; linearpredict with direction=:backward can rebuild them.

Annotations (annotate) and sample metadata (addsampleinfo) are applied as for loadnmr.

Examples

NMRTools.NMRIO.SchemaMigrate — Module

Migrate NMR sample metadata to the latest schema version.

Call loadsample(path, migrationspath=MIGRATIONSPATH[]) to load a JSON file and apply migrations. It returns the migrated data as a Dict.

Call updatetolatestschema!(data) with a parsed JSON Dict. It modifies the dict in place and returns it.

The migration patch file is expected at current/patch.json relative to this module. Override by setting MIGRATIONSPATH[] or passing migrationspath.
