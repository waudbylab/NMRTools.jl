Sample metadata schema

Sample metadata are JSON files describing the physical sample, following the NMR sample schema. NMRTools reads the version bundled with it (v0.4.0) and migrates files written with earlier versions. A sample file is associated with an experiment when the experiment's date falls between the file's created_timestamp and ejected_timestamp; sample files are looked for in the folder that contains the experiment folders.

Fields are read with sample, passing the section and field names; see Find sample information.

When a field such as solvent or isotopic_labelling has the value "custom", sample returns the corresponding custom_… field instead.

people

People

FieldTypeDescription
usersarrayPeople involved in this experiment
groupsarrayResearch groups (surnames) involved in this experiment

sample

Sample

FieldTypeDescription
labelstringQuick sample identifier
physical_formstringPhysical form of sample
componentsarraySample components (allows for multiple components)

buffer

Buffer

FieldTypeDescription
phnumberBuffer pH
componentsarrayBuffer components and their concentrations
chemical_shift_referencestringChemical shift reference compound
reference_concentrationnumberConcentration of chemical shift reference
reference_unitstringUnit for reference concentration
solventstringSolvent composition
custom_solventstringCustom solvent description if 'custom' is selected above

nmr_tube

NMR tube or rotor properties

FieldTypeDescription
diameter_mmnumberNMR tube or rotor diameter (mm)
typestringType of NMR tube or rotor
sample_volume_uLnumberSample volume (µL)
sample_mass_mgnumberSample mass (mg)
rack_idstringIdentifier for SampleJet rack
rotor_serialstringRotor serial number

reference

Cross-references for lab notebooks etc.

FieldTypeDescription
sample_idstringLocal sample identifier
labbook_entrystringReference to laboratory notebook entry

notes

Free text field for additional notes and observations

Type: string

metadata

Metadata

FieldTypeDescription
created_timestampstringISO 8601 timestamp when this record was created
modified_timestampstringISO 8601 timestamp when this record was last modified
ejected_timestampstringISO 8601 timestamp when this sample was ejected
schema_versionstringVersion of this schema used
schema_sourcestringSource of this schema version
