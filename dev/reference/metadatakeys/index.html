Metadata keys

The standard metadata keys set when data are loaded and processed. See Metadata for how metadata are organised.

Accessing metadata

LookupReturns
spec[:ns]spectrum metadata (a key from Spectra)
spec[F1Dim, :swppm], spec[1, :swppm]axis metadata (a key from Frequency and time dimensions), by dimension type or number
acqus(spec, :te)an acquisition parameter from the acqus file
acqus(spec, :p, 1)an arrayed acquisition parameter (here P1), indexed as in TopSpin
acqus(spec, :vdlist)an auxiliary file (see Auxiliary files)
metadata(spec), metadata(spec, F1Dim)the whole dictionary for the spectrum, or for one axis
using NMRTools
spec = exampledata("2D_HN")
spec[:ns], spec[F1Dim, :swppm], acqus(spec, :p, 1)
(2, 18.031507535006423, 9.199999999999998e-6)

Times are in seconds and frequencies in Hz (see Time and frequency units).

Frequency and time dimensions

Keys marked † are set on time dimensions by loadfid and carried over to the frequency dimension by ft.

KeyDescription
:aqacquisition time, in seconds
:bfbase frequency, in Hz
:firstpoint †scaling factor applied to the t = 0 point
:grpdly †digital filter group delay, in dwell times (direct dimension; 0 after ft)
:labelshort label
:mcindeximaginary unit of the dimension (1 for im1, …), nothing if none
:npointsfinal number of real data points in dimension (after extraction)
:nucleusNucleus of the dimension
:offsethzcarrier offset from bf, in Hz
:offsetppmcarrier offset from bf, in ppm
:phasetotal phase correction applied, (p0=…, p1=…) in degrees, p0 at the first point
:pseudodimflag indicating non-frequency domain data (false for frequency domain)
:quadrature †quadrature scheme of an indirect dimension, e.g. :states_tppi
:referenceoffsetapplied referencing, in ppm
:regionextracted region, expressed as a range in points, otherwise missing
:sfcarrier frequency, in Hz
:swhzspectrum width, in Hz
:swppmspectrum width, in ppm
:tdnumber of complex points acquired, including LP
:tdzfnumber of complex points when FT executed, including LP and ZF
:windowWindowFunction encoding applied apodization

Auxiliary files

Auxiliary files in the experiment folder are read when data are loaded and returned by acqus, with their values converted to NMRTools units:

KeyContents
:vclistvariable loop counters (dimensionless)
:vdlistvariable delays, in seconds
:valistvariable amplitudes, in dB (converted from W if necessary)
:vplistvariable pulse lengths, in seconds
:fq1list … :fq8listfrequency lists, as FQList (see Frequency lists)

acqus returns nothing for a list that is not present.
